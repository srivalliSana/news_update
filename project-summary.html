01
Project Overview
What was built and why
🎯

A fully functional college news portal for Centurion University of Technology and Management (CUTM) — similar to Times of India / NDTV in layout and behaviour, but customised for a university audience. News articles appear in descending time order (newest first) and older ones move down into an archive.

🌐 Frontend
  • ✅ News portal homepage (index.html)
  • ✅ Archive page (archive.html)
  • ✅ Breaking news ticker
  • ✅ Featured hero article
  • ✅ Category filter navigation
  • ✅ Search overlay
  • ✅ Article full-read modal
  • ✅ Dark mode (persists)
  • ✅ Fully responsive (mobile)
⚙️ Backend
  • ✅ Node.js + Express server
  • ✅ REST API for articles
  • ✅ Admin portal (admin.html)
  • ✅ Slack slash command integration
  • ✅ JSON file storage (no database)
  • ✅ Auto-seed 18 default articles
  • ✅ Ticker management via API
  • ✅ Quick links management via API
  • ✅ Token-based admin auth
02
File Structure
Every file in the project and its purpose
  • 🟢
    server.js
    Main Node.js/Express backend — serves the website, handles all API routes, Slack commands, admin auth, and auto-seeds articles on first run.
  • 🔵
    index.html
    Homepage — breaking ticker, hero article, news card feed, sidebar with recent updates, quick links, section counts.
  • 🔵
    admin.html
    Admin portal — 5-tab interface: Articles (full CRUD), Announcements (ticker), Quick Links, Slack config, Settings (password).
  • 🔵
    archive.html
    Archive page — all articles grouped by date, filterable by section and month, searchable.
  • 🟡
    app.js
    Frontend JavaScript for homepage — fetches articles, ticker, quick links from API; handles filters, modals, search, dark mode.
  • 🟡
    archive.js
    Frontend JavaScript for archive page — groups articles by date, applies filters, renders archive items and modals.
  • 🟡
    data.js
    Static fallback (currently empty — all data lives in articles.json managed by server).
  • 🟢
    style.css
    Complete stylesheet — CUTM navy + amber brand colours, badge system for 8 sections, dark mode, responsive breakpoints, animations.
  • 🔷
    articles.json
    Article database — all articles stored as JSON. Pre-seeded with 18 dummy CUTM articles. Managed via admin portal and Slack commands.
  • 🔷
    site-settings.json
    Stores the scrolling ticker announcements and sidebar quick links. Edited via Admin → Announcements and Admin → Quick Links.
  • 🔷
    config.json
    Stores admin password and Slack signing secret. ⚠️ Excluded from GitHub (.gitignore) — lives only on your machine.
  • 🔷
    package.json
    Node.js project config — dependencies: express, dotenv. Dev dependency: nodemon.
  • 🟢
    .gitignore
    Tells git what NOT to upload: node_modules/, .env, config.json (passwords/secrets).
  • 🟢
    .env.example
    Template for environment variables (PORT). Copy to .env and fill in values.
03
Website Features
What visitors see and can do
📢 Breaking News Ticker
Scrolling announcement bar at the top. Items are fully editable from the admin panel → Announcements tab. Pauses on hover.
🖼️ Featured Hero Article
Full-width image hero at the top of the feed. Any article can be set as featured from admin. Zooms on hover.
⏱️ Newest First Order
Articles always appear newest at top, oldest at bottom. Toggle between Newest/Oldest First with sort buttons.
🗂️ Section Filter Nav
Sticky navigation bar with 8 college sections. Click any section to filter the feed instantly.
🔍 Search Overlay
Press the Search link or / key. Searches across title, summary, section, and tags in real-time.
📖 Full Article Modal
Click any card to open the full article in a pop-up modal with title, author, date, image, full content, and tags.
📦 Archive Page
All articles grouped by date. Filter by section, month, or search. Archived articles show an "Archived" badge.
🌙 Dark Mode
Toggle with the Dark Mode link in the top bar. Preference saved in localStorage — persists on next visit.
📱 Fully Responsive
Hamburger menu on mobile. Single-column card layout on small screens. Archive items stack vertically.
🔗 Dynamic Quick Links
Sidebar quick links are managed from the admin panel → Quick Links tab. Changes appear on the website instantly.

# Start the server
npm start

npx nodemon server.js

06
Admin Portal
admin.html — Full content management system
🔐

URL: http://localhost:3000/admin.html  |  Default password: cutm@admin  |  Change password from Settings tab after first login.

📰
Articles — Full CRUD
View all articles with stats (Total / Live / Archived / Featured). Search and filter by section or status. Add new articles with a full form (title, section, author, summary, full HTML content, image URL with preview, tags). Edit any existing article by clicking the ✏️ pencil icon — all fields are pre-filled. Toggle ⭐ Featured (only one at a time), 📢 Notice badge, Archive/Restore, and Delete with confirmation.
📢
Announcements — Ticker Management
Edit the scrolling ticker that runs across the top of the website. Add new announcement items, edit existing text inline, remove items with ✕, and drag-to-reorder. Click "Save All Announcements" and changes appear on the live website immediately.
🔗
Quick Links — Sidebar Links
Manage the Quick Links widget in the website sidebar. Each link has a Label, a URL, and an External toggle (opens in new tab). Add, remove, edit, and drag-to-reorder links. Save to update the live website instantly.
💬
Slack — Signing Secret Configuration
Paste your Slack App Signing Secret here (from Slack App → Basic Information → App Credentials). Status pill shows Configured (green) or Not Configured (red). The server reads the secret from config.json on every request — no restart needed after saving. Also shows all 4 slash command URLs ready to copy into Slack and a full setup guide.
⚙️
Settings — Admin Password
Change the admin portal password. Minimum 6 characters. Must be confirmed. Takes effect immediately — use the new password on next login.
07
Slack Integration
Publish news articles directly from a Slack channel
⚡ How it works
Slack Channel → /publish command → Node.js Server → saves to → articles.json → fetched by → Website
📋 Slash Commands
CommandEndpointWhat it does
/publishPOST /slack/publishCreate and publish a new article on the website
/list-newsPOST /slack/listShow the 10 most recent articles with IDs (private reply)
/archive-newsPOST /slack/archiveMove an article to archive by ID (removes from main feed)
/delete-newsPOST /slack/deletePermanently delete an article by ID
💬 Command Examples (type in Slack)
/publish Campus | New Library Wing Opens | The 3-floor library was inaugurated by the Vice-Chancellor today. | Editorial Desk
/publish Placements | TCS Selects 30 Students | Campus drive concludes with 30 offers at ₹3.6 LPA. | Placement Cell | https://images.unsplash.com/photo-1521737604893-d14cc237f11d?w=800
/list-news
/archive-news 105
/delete-news 108

Format: /publish Section | Title | Summary | Author | ImageURL (optional)

🛠️ Slack App Setup Steps
  1. Start your serverRun npm start on your computer
  2. Expose publicly with ngrokInstall ngrok (free) → run ngrok http 3000 → copy the https://xxxx.ngrok.io URL
  3. Create Slack AppGo to api.slack.com/apps → Create New App → From scratch → name it "CUTM News Bot"
  4. Add Slash CommandsApp Settings → Slash Commands → Create 4 commands: /publish, /list-news, /archive-news, /delete-news with the ngrok URLs
  5. Copy Signing SecretApp Settings → Basic Information → App Credentials → Signing Secret → paste into Admin Portal → Slack tab
  6. Install AppSettings → Install App → Install to Workspace → Allow
  7. Test itGo to any Slack channel and type /publish Campus | Test Article | This is a test. | Editorial Desk

09
Database / Storage
How data is stored (no database needed)
📄 articles.json

Array of article objects. Each has: id, title, summary, content (HTML), category, author, image, timestamp (ISO), featured, breaking, archived, tags[].

Auto-seeded with 18 articles on first run.

⚙️ site-settings.json

Two keys:
ticker — array of strings shown in the scrolling bar.

quickLinks — array of {label, url, external} objects shown in the sidebar widget.

Edited via admin panel.

🔑 config.json

Two keys:
adminPassword — default: cutm@admin

slackSigningSecret — your Slack app's signing secret. Set from Admin → Slack tab.

⚠️ In .gitignore — never pushed to GitHub.

How to Use — Step by Step
Getting started from scratch
🚀 Run the Project
  1. Clone from GitHubgit clone https://github.com/srivalliSana/news_update.git then cd news_update
  2. Install dependenciesRun npm install — installs express and dotenv
  3. Start the serverRun npm start — server starts on port 3000, articles.json is seeded automatically
  4. Open the websiteVisit http://localhost:3000 in your browser
  5. Open the admin portalVisit http://localhost:3000/admin.html and log in with cutm@admin
  6. Change admin passwordAdmin → Settings tab → enter new password → Update Password
✏️ Publish a New Article

Via Admin Panel

  1. Open Admin Portalhttp://localhost:3000/admin.html
  2. Articles tab → + Add ArticleFill in all fields
  3. Click Publish ArticleAppears on website immediately

Via Slack

  1. Set up Slack appSee Section 07
  2. Type in any channel/publish Section | Title | Summary | Author
  3. DoneChannel sees confirmation, article is live
⚠️ Important Notes
⚠️

config.json is never pushed to GitHub — so after cloning on a new machine, you need to set your admin password and Slack secret again via the admin portal. The server uses defaults (cutm@admin) if config.json doesn't exist.

⚠️

Slack slash commands need a public URL — use ngrok (ngrok http 3000) while developing locally. For production, deploy to a cloud service like Railway, Render, or a VPS.

✅

Remove dummy data later — go to Admin → Articles → delete or replace the 18 sample articles, or just edit them with real CUTM content.
